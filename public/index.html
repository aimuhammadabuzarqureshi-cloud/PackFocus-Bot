🚀 WordPress Installation

Add this single line to your WordPress theme's footer.php (before the closing </body> tag), or use a plugin like "Insert Headers and Footers":

<script src="https://YOUR_SERVER_URL/widget.js" data-chatbot-server="https://YOUR_SERVER_URL"></script>

✨ Features

  • 🤖 AI-powered conversations via Google Gemini / OpenRouter
  • 📦 Product information and catalog browsing
  • 🖼️ Logo upload with AI mockup generation
  • 💬 Multi-turn conversation memory
  • 📱 Fully responsive on mobile and desktop
  • 🎨 Premium dark-mode UI with animations

⚙️ Configuration

Edit the .env file to customize:

  • AI_PROVIDER — choose "gemini" or "openrouter"
  • OPENROUTER_API_KEY — Your OpenRouter API key
  • OPENROUTER_MODEL — Model name e.g., google/gemma-4-31b-it:free
  • COMPANY_NAME — Your client's company name
  • COMPANY_DESCRIPTION — Brief company description
  • PRODUCT_CATALOG — Comma-separated list of products/services
